2. 数据模型建议

{
  "version": 2,
  "polygons": [
    {
      "id": "poly-001",
      "points": [{ "x": 12.5, "y": 34.2 }, { "x": 45.8, "y": 34.2 }],
      "label": "储罐区",
      "color": "#ff4d4f",
      "color_source": "auto"
    }
  ]
}
  • 现有 risk_zones.floor_plan_polygon 保留，旧版 points 结构可兼容读取。
  • 风险点继续使用 risk_objects.location_x / location_y，新风险点创建 risk_objects 并设置 is_risk_point=true。
  • 手动颜色覆盖记录 color_source: manual；自动色仍由分区内最高风险等级计算。
