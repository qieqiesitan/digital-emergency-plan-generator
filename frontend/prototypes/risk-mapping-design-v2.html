2. 楼层管理

企业编辑页 维护楼层名称、排序、每层平面图上传。
工作台 顶部楼层切换，分区列表和画布按当前楼层过滤。
总览页 楼层切换，渲染当前楼层多边形和风险点。
兼容旧数据 原有 enterprise.floor_plan_url 迁移为默认楼层/总图。

3. 数据模型 v2

enterprise_floors: id / enterprise_id / name / floor_no / image_url / sort_order
risk_zones.floor_id: NOT NULL
risk_objects.floor_id: nullable（未设置时沿用所属分区楼层）
floor_plan_polygon: { "version": 2, "polygons": [{ "points": [...] }] }
  • 风险分区不可跨楼层，因此 floor_plan_polygon 不需要给每个 polygon 再存 floor_id。
  • 同一分区可在同一楼层内包含多个不相邻区域。
  • 风险点来源仍是 risk_objects，工作台切换楼层时只展示当前楼层风险点。
