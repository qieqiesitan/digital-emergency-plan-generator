多层厂房方案

在企业有多层厂房、多个楼栋、多张平面图时，需要先决定楼层维度进入首版还是预留。

当前问题：首版是否完整支持楼层，还是先做单层并预留数据字段？

你希望多层怎么处理？

在页面点击卡片可标记选择，最终请也在终端回复 A / B / C。

A

单层先行，预留多层（推荐）

首版工作台只编辑一个画布；数据结构先加 floors / floor_id，二期再开放楼层切换。

首版：单层完整

限制：多层企业暂时只能先画一层，或按总图近似表达。
B

首版完整支持多层

企业可维护楼层列表和每层平面图；工作台和总览都支持楼层切换，分区/风险点/多边形都带 floor_id。

C

数据模型建议
enterprise_floors: id / enterprise_id / name / floor_no / image_url / sort_order
risk_zones.floor_id: nullable
risk_objects.floor_id: nullable
floor_plan_polygon.polygons[].floor_id: nullable

floor_id 为空时表示“总图 / 全厂平面”，非空时表示该分区或风险点属于某层。这样首版可以先不实现楼层 UI，但二期不需要改表。
