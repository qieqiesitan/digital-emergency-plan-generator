当前问题：工作台首版需要哪些绘图工具？

你希望首版工具集做到哪一档？

在页面点击卡片可标记选择，最终请也在终端回复 A / B / C。

A

核心工具（推荐）

足够画四色分布图，不引入复杂绘图能力。

  • 矩形 / 多边形
  • 选择 / 移动 / 顶点编辑
  • 删除 / 撤销 / 重做
  • 风险点：拖动已有 / 新建
  • 文字标签 / 图例
  • 画布缩放 / 平移
优点：覆盖主流程，开发量可控。
限制：没有自由画笔、网格和图层。
B

核心 + 自由画笔

在核心工具基础上，允许徒手圈出复杂边界。

  • 核心工具全部能力
  • 自由画笔：手绘闭合区域
  • 画笔平滑 / 转多边形
优点：适合不规则厂房、山坡、复杂边界。
限制：手绘转多边形需要额外处理。
C

完整工具

在 B 基础上，加入网格、辅助线和图层管理。

  • 核心 + 自由画笔
  • 网格 / 吸附
  • 辅助线 / 标尺
  • 图层：平面图底图 / 分区 / 风险点
优点：最接近专业制图体验。
限制：首版开发量最大。
