### 需修复的问题

**1. SVG 文本/属性未转义（XSS/无效 XML 风险）**

所有用户数据（事件名、分区名、风险点名、资源名、坐标数值）插入 SVG 前需转义。新增辅助函数：

```python
import html as _html


def _esc(v) -> str:
    """转义 SVG 文本内容。"""
    return _html.escape(str(v), quote=True)
```

对 `build_risk_matrix_svg` 的事件名、`build_evacuation_svg` 的分区名/风险点名/资源名使用 `_esc(...)` 包裹；坐标数值用 `float()` 格式化。

**2. 输入契约与真实模型不符**

- `build_evacuation_svg` 的 zones 元素真实结构为 `{"name": ..., "floor_plan_polygon": {"version":2, "polygons": [{"points": [...]}]}}`，当前代码读 `z.get("polygon")`。改为兼容两者：

```python
        poly = z.get("floor_plan_polygon") or z.get("polygon") or {}
```

- `polygons` 的 points 可能是 `{"points": [[x,y],...]}` 的 dict 值，也可能直接是 list——当前 `p.get("points", [])` 对 dict 会失败。改为：

```python
        pts_raw = p.get("points", []) if isinstance(p, dict) else []
        pts = [tuple(pt) for pt in pts_raw if isinstance(pt, (list, tuple)) and len(pt) >= 2]
```

- `location_x/location_y` 可能为 None：`_to_view` 前用默认值兜底（`o.get("location_x") or 50`）。
- 风险事件 `likelihood/severity` 可能是中文或非数字：`build_risk_matrix_svg` 过滤时用安全数值化：

```python
def _to_int(v, default: int) -> int:
    try:
        return min(max(int(float(v)), 1), 5)
    except (TypeError, ValueError):
        return default
```

过滤条件改为 `likelihood/severity` 经 `_to_int` 后可得到 1-5 即视为有效（不再要求原始值 truthy）。
