### 问题 2（健壮性）：compute_completion 接受可选 Enterprise 实例 + _org_done 防御

`backend/app/services/onboarding_service.py`：

1. `compute_completion(enterprise_id, db, enterprise: Enterprise | None = None)`：若传入 enterprise 实例则复用，否则查询；企业不存在抛 ValueError。
2. `_org_done` 防御：`group.get("members") or []`，并跳过非 dict 成员。

```python
def _org_done(org_structure: list | None) -> bool:
    for group in org_structure or []:
        if not isinstance(group, dict):
            continue
        for member in group.get("members") or []:
            if not isinstance(member, dict):
                continue
            role = str(member.get("role", "") or "")
            if member.get("name") and ("总指挥" in role or role == "chief" or role == "commander"):
                return True
    return False
```
