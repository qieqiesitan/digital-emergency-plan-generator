把 `compute_risk` 内「按阈值区间匹配等级 + 未命中兜底低」的循环替换为调用 `level_from_score(method_type, r, thresholds)` 得到等级，再按该等级（或按原循环等价逻辑）取 `action`/`deadline`。**必须保持现有行为不变**：命中的 action/deadline 取自该阈值项，未命中时等级「低」且 action=「日常管理」、deadline=「持续」（与现状一致）。实现方式举例：

```python
    level = level_from_score(method_type, r, thresholds)
    matched = next((t for t in thresholds or [] if t["min"] <= r <= t["max"]), None)
    if matched:
        return RiskResult(risk_level=level, risk_score=score_str,
                          action=matched.get("action", ""), deadline=matched.get("deadline", ""))
    return RiskResult(risk_level=level, risk_score=score_str, action="日常管理", deadline="持续")
```
