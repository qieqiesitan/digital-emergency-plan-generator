### 需修复的问题

**1（严重）：L2 存在性检查失效**

`_regulation_exists` 中空 `full_name` 节点会导致 `norm in ""` 为 False 但 `"" in norm` 为 True，使任意引用都「存在」。修复：跳过空 full_name，且比对双方均非空：

```python
def _regulation_exists(ref: str, index: list | None) -> bool:
    if not index:
        return True  # 库不可用时不误报
    norm = _normalize(ref)
    for full in index:
        full_norm = _normalize(full)
        if not full_norm:
            continue
        if norm in full_norm or full_norm in norm:
            return True
    return False
```

**2（重要）：缺废止检查与全半角归一化**

规格要求：库中标记已废止 → warning。`_load_regulation_index` 需同时返回 full_name 与 status；`_normalize` 需归一化全半角（数字/字母）。

```python
def _normalize(text: str) -> str:
    """去除空白并归一化全半角。"""
    result = re.sub(r"\s+", "", text or "")
    result = result.translate(str.maketrans("０１２３４５６７８９ＡＢＣＤＥＦＧＨＩＪＫＬＭＮＯＰＱＲＳＴＵＶＷＸＹＺ",
                                           "0123456789ABCDEFGHIJKLMNOPQRSTUVWXYZ"))
    return result


def _load_regulation_index() -> dict | None:
    """加载法规库 graph.json：{norm_full_name: status}；失败返回 None。"""
    global _reg_index_cache, _reg_index_loaded
    if _reg_index_loaded:
        return _reg_index_cache
    _reg_index_loaded = True
    try:
        import json as _json
        from pathlib import Path
        p = Path(__file__).parent.parent / "regulations" / "data" / "graph.json"
        data = _json.loads(p.read_text(encoding="utf-8"))
        _reg_index_cache = {
            n.get("full_name", ""): n.get("status", "effective")
            for n in data.get("nodes", []) if n.get("full_name")
        }
    except Exception:
        _reg_index_cache = None
    return _reg_index_cache
```
