**2（规格缺失）：E3 第三条规则未实现**

规格 §3.3 E3：「有风险点但应急资源数量均为 0 的类别 → warning」。当前只实现了缺消防/急救类。

修复：传入的资源中，若类别下所有 quantity 均为 0 且企业有风险点（ent_data 或 plan 存在风险）：

```python
    # E3 第 3 条：资源数量为 0 的类别（需风险点存在时才有意义）
    has_risk = bool(getattr(plan, "risk_sources", None)) or bool(getattr(plan, "total_events", 0))
    if has_risk:
        zero_cats = {
            getattr(r, "category", "") or r.get("category", "")
            for r in resources
            if (getattr(r, "quantity", 0) if hasattr(r, "quantity") else r.get("quantity", 0)) == 0
        }
        for c in zero_cats:
            if c:
                warnings.append({
                    "section_key": "",
                    "section_title": "",
                    "warning": f"{c}应急资源数量为 0",
                })
```

注意：`plan` 是 MagicMock，`risk_sources`/`total_events` 不存在时 getattr 返回 None/0 → 不触发，测试需显式设置。若实现时发现 plan 无风险字段可靠来源，可在 check_plan 增加可选参数 `has_risk: bool = False` 由调用方传入；export.py 传 `has_risk=bool(risk_objects 或风险点数量)`。

**3（误报）：E1 座机带连字符**

当前 `\d{5,}` 提取会把 `029-88888888` 拆成 `029` 与 `88888888` 两个数字，`029` 不匹配任何白名单 → 误报。修复：先整体匹配带连字符的座机，再提取其余数字：

```python
    for s in sections:
        text = _strip_html(s.content)
        # 先整体匹配座机（带连字符），避免拆分误报
        cleaned = re.sub(r"0\d{2,3}-\d{7,8}", "", text)
        for num in re.findall(r"\d{5,}", cleaned):
            if not re.fullmatch(r"1[3-9]\d{9}", num) and not re.fullmatch(r"0\d{2,3}-?\d{7,8}", num):
                warnings.append({
                    "section_key": s.section_key,
                    "section_title": s.title,
                    "warning": f"疑似联系电话格式错误：{num}",
                })
```
