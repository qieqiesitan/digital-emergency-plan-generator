```python
from typing import Literal
from pydantic import BaseModel


class SignItem(BaseModel):
    category: Literal["warning", "prohibition", "instruction", "notice"]
    name: str
    svg_name: str


class RightColumn(BaseModel):
    hazard_description: str = ""
    accident_types: list[str] = []
    control_measures: list[str] = []
    emergency_measures: list[str] = []


class CardData(RightColumn):
    object_id: str
    enterprise_name: str
    name: str
    code: str
    level: str
    level_color: str
    responsible_unit: str
    responsible_person: str
    contact_phone: str
    fallback_used: bool = False
    signs: list[SignItem] = []
    snapshot: dict | None = None
    stale: bool = False
    public_url: str
    generated_at: str


class CardSummary(BaseModel):
    object_id: str
    name: str
    zone_name: str = ""
    level: str
    level_color: str
    accident_types: list[str] = []
    signs: list[SignItem] = []
    responsible_unit: str = ""
    snapshot: dict | None = None
    stale: bool = False
    public_url: str


class ExportRequest(BaseModel):
    object_ids: list[str]


class ExportResponse(BaseModel):
    file_key: str


class AiOptimizeResponse(BaseModel):
    original: RightColumn
    optimized: RightColumn


class SnapshotSaveRequest(BaseModel):
    content: RightColumn
```

```python
    ent = Enterprise(name="测试公司", safety_officer="李四", safety_officer_phone="13900000000")
```

### 第三部分：实现组装服务（`backend/app/services/risk_notice_card_service.py`）

完整代码见计划文档任务 5（`docs/superpowers/plans/2026-08-11-risk-notice-card.md`），核心函数：

* `compute_level(events)`：按 LEVEL_ORDER 取最高等级，空列表返回"未评估"
* `resolve_responsible(obj, ent)`：对象字段优先，兜底企业安全负责人，返回 (unit, person, phone, fallback)
* `compute_code(objects, obj)`：按对象列表序号生成 FX-{序号:03d}
* `_dedupe` / `_numbered`：去重与 ①②③ 编号
* `build_right_column(events, measures, snapshot=None)`：快照优先；危险因素=trigger_conditions+consequences 归并；事故类型去重；管控措施=engineering/management/ppe 编号；应急处置=emergency 措施优先+模板兜底（不足 2 条补模板，全部 20 类模板按事故类型取，仍空用通用模板）
* `match_signs(accident_types)`：按 SIGN_GROUPS 合并去重，按 SIGN_CATEGORY_ORDER 排序，每类别最多 2 个，返回 list[SignItem]
* `is_stale(snapshot, source_updated_at)`：快照 updated_at < 源数据最新 updated_at
* `get_snapshot(db, object_id)`：查最新快照
* `load_events_and_measures(db, object_id)`：加载对象的事件与措施（含 units 下的事件）
* `build_card_data(db, ent, obj, objects, events, measures)`：组装 CardData（快照优先、stale 判定、public_url=/r/{token}）

```python
async def save_snapshot(
    db: AsyncSession,
    enterprise_id: str,
    object_id: str,
    user_id: str,
    content: dict,
) -> RiskNoticeCard | None:
    existing = await get_snapshot(db, object_id)
    if existing:
        existing.version += 1
        existing.content = content
        existing.source = "ai"
        existing.created_by = user_id
        await db.commit()
        await db.refresh(existing)
        return existing
    snap = RiskNoticeCard(
        enterprise_id=enterprise_id,
        object_id=object_id,
        version=1,
        content=content,
        source="ai",
        created_by=user_id,
    )
    db.add(snap)
    await db.commit()
    await db.refresh(snap)
    return snap
```
