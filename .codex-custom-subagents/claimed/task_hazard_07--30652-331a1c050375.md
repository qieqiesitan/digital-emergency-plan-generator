## 契约

**文件**：`backend/app/routers/hazard_management.py`（追加）、新建 `backend/tests/test_hazard_review_api.py`。端点沿用 router 既有前缀 `/enterprises/{enterprise_id}/hazard-inspection`。

**核心接线**：状态机 `hazard_state_machine.apply_transition(db, record, action, actor_user, actor_role, payload, enterprise)` 已实现（勿改）。本任务在路由层接线三个动作：

- rectify：payload 支持 content/evidence/reviewer_user_id；状态机 `_apply_rectify` 校验整改人本人（enterprise_admin 例外）+ 写 HazardRectification + 设置 reviewer_user_id + 状态→reviewing。
- review：payload 支持 result（pass/fail）/comment/evidence；状态机 `_apply_review` 校验复查人本人 + 按 strict+重大 决定停留/→second_review/fail→rectifying。
- close：payload 支持 comment；仅 enterprise_admin；reviewing/second_review→closed（写 review_type=close + closed_at）；严格+重大 close 前必须 second_review（状态机校验）。
- **actor_role 映射**：整改人本人 → "rectifier"、指定复查人 → "reviewer"、企业主/启用 enterprise_admin → "enterprise_admin"（与 ROLE_GATE 一致；任务 6 已有企业主映射先例，复用同一判定后按动作传对应角色，报告说明）。

**1. `POST /records/{rid}/rectify`（整改提交）**

- body：content（必填非空）、evidence（可选照片数组）、reviewer_user_id（必填；复查人 ≠ 整改人 422，从 enterprise_members 校验 enabled，且不能等于 record.rectification_user_id）。
- 权限：记录归属 404；执行=整改人本人（record.rectification_user_id）或企业主/启用 enterprise_admin（其余 403/422 由状态机语义分层）。
- 接线 apply_transition(db, record, "rectify", user, role, payload, ent)。
- **复查期限提醒（规格 §10）**：rectify 成功后按数据字典 `deadline_rules.review` 天数计算复查期限（date.today() + review_days），创建 `HazardNotification`（type="review_due"，user_id=复查人，message 含「请于 YYYY-MM-DD 前完成复查」中文文案，record_id 回填），供任务 8 超期扫描使用；字典缺 review 天数时不创建或创建无期限文案（说明取舍）。返回含 review_deadline 信息。

**2. `POST /records/{rid}/review`（复查/二次复核）**

- body：result（pass/fail 必填）、comment（可选）、evidence（可选）。
- 权限：记录归属 404；执行=指定复查人（record.reviewer_user_id）或企业主/启用 enterprise_admin（其余 403/422 分层）。
- 接线 apply_transition；strict+重大 pass→second_review、fail→退回 rectifying、standard 一般 pass 停留 reviewing（状态机决定，路由透传）。

**3. `POST /records/{rid}/close`（销号）**

- body：comment（可选）。
- 权限：仅企业主/启用 enterprise_admin（403）；状态非 reviewing/second_review → 409；严格+重大未 second_review → 409/422（状态机抛，路由透传）。
- 接线 apply_transition；成功返回 closed + closed_at。
