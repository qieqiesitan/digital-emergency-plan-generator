### 需修复的问题

#### 问题 1（严重）：_role_matches 把副总经理误判为总指挥

当前总指挥分支 `("总指挥" in pos and "副总指挥" not in pos) or "总经理" in pos`——「总经理」是「副总经理」的子串，导致 position="副总经理" 被误判为承担「总指挥」。

修复：总经理分支同样排除副总经理：

```python
def _role_matches(member: dict, role: str) -> bool:
    """判断成员是否承担某角色：职务名精确/包含匹配，或总经理→总指挥/副总经理→副总指挥。"""
    pos = (member.get("position") or "") + (member.get("role") or "")
    if not pos:
        return False
    if role == "副总指挥":
        return "副总指挥" in pos or ("副总经理" in pos and "总经理" not in pos)
    if role == "总指挥":
        return ("总指挥" in pos and "副总指挥" not in pos) or ("总经理" in pos and "副总经理" not in pos)
    return role in pos
```
