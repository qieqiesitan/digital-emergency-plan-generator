### 步骤 3：实现签署人构建函数

```python
def _build_signers_from_org(org_structure: list | None) -> list[dict]:
    """组织架构 → 签署人列表（跳过无姓名成员）。"""
    signers = []
    for g in org_structure or []:
        for m in g.get("members", []):
            if m.get("name"):
                signers.append({"seq": len(signers) + 1, "name": m["name"], "title": m.get("position", "")})
    return signers
```
