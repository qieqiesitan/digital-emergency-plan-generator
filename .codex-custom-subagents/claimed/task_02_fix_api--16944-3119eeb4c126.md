## 修复清单

**必须修复 1：`backend/app/routers/data_dicts.py` 5 个写接口缺 `data` 字段**

`ApiResponse.data` 无默认值，`return ApiResponse(message="...")` 会抛 `ValidationError`（HTTP 500）。把 5 处（create_system_dict / update_system_dict / create_enterprise_dict / update_enterprise_dict / delete_enterprise_dict）改为：

```python
return ApiResponse(data={}, message="已创建")
```

（各接口文案保持原样：已创建 / 已更新 / 已删除（恢复系统默认）。）

**建议修改 2：`backend/tests/test_data_dict.py` `test_enterprise_overrides_system` 开头加缓存清理**

```python
    invalidate_dict_cache("ent-1", "measure_factors")
```

与另外两个异步用例保持一致，避免用例重排时命中缓存。

**建议修改 3：测试文件 import 合并置顶**

把 `import pytest`、`from unittest.mock import AsyncMock, MagicMock`、`from app.services.data_dict_service import get_dict_map, invalidate_dict_cache`、`from app.models.data_dict import DataDict` 统一放到文件顶部（去重），文件内不再出现中部 import。

**建议修改 4：`test_disabled_entry_excluded` 去掉空断言**

`assert "ppe" not in merged` 是空断言（mock 数据没有 ppe 行）。删除该断言，保留已有效的 `db.execute.assert_awaited_once()` 与查询文本含 `enabled` 过滤的断言（若后者已存在则保留）。

**建议修改 6：schema 默认值与更新语义**

`backend/app/schemas/data_dict.py`：

- `value: dict = {}` 改为 `value: dict = Field(default_factory=dict)`（import `Field`）；
- `DataDictUpdate.value` 允许显式传 `null` 会把 JSONB 置 NULL 导致 commit 报错——把 `data_dicts.py` 中两个 update 接口的 `model_dump(exclude_unset=True)` 改为 `model_dump(exclude_unset=True, exclude_none=True)`。

**建议修改 7：响应模型类型化**

新增 `DataDictResponse`（字段同 `_serialize` 输出：id/dict_type/code/label/value/scope/enterprise_id/sort_order/enabled/is_system/description），`_serialize` 改为返回该模型或保持 dict 但路由 `response_model=ApiResponse[list[DataDictResponse]]`（选一种，保证 OpenAPI 类型化；若用 pydantic 模型则 `model_config={"from_attributes": True}`）。

**仅供参考项不处理**（缓存竞态接受、enterprise_id=None 冗余、B 阶段接入等），但可在最终回复中说明。
