### 修复方案

**1. 轮询改为多次轮询**

在 `PlanEditorScreen.tsx` 中将单次 5 秒查询改为轮询：每 15 秒查一次 `getGenerationStatus`，最多 8 次（约 2 分钟），条件满足即停止：

```typescript
async function pollGenerationStatus(planId: string, attempts = 8, intervalMs = 15000) {
  for (let i = 0; i < attempts; i++) {
    await new Promise((r) => setTimeout(r, intervalMs));
    try {
      const status = await getGenerationStatus(planId);
      const failed = status?.data?.failed_sections ?? [];
      if (!status?.data?.generating || failed.length > 0) {
        setFailedSections(failed);
        return failed;
      }
    } catch {
      // 轮询失败继续尝试
    }
  }
  return [];
}
```

轮询结束后 `invalidateQueries(["plan-sections", planId])` 刷新章节，并展示失败提示条（非空时）。
