- `fieldInit`：对 `established_date` 返回 `enterprise.established_date ? dayjs(enterprise.established_date) : undefined`；其它字段原样。

- 保存回调：`validateFields` 后把 `established_date` 序列化为 `YYYY-MM-DD` 字符串再传回调：

```tsx
const values = await form.validateFields();
const payload: Record<string, unknown> = { ...values };
if (payload.established_date) {
  payload.established_date = dayjs(payload.established_date as dayjs.Dayjs).format("YYYY-MM-DD");
}
if (onCreate) await onCreate(payload);
else if (onSaved) await onSaved(payload);
```

（onCreate/onSaved 改为二选一，避免同时触发。）
