5.3 应急响应分级
依据事件危害程度 · 影响范围 · 控制能力，分为三级响应
2,341 字

（1）Ⅰ级响应（红色）。发生重大及以上事故，或事故超出企业自身控制能力时，由应急指挥部总指挥宣布启动Ⅰ级响应，立即向政府部门报告并请求支援，同时组织全员疏散与先期处置。

（2）Ⅱ级响应（橙色）。发生较大事故，影响范围限于厂区内时，由分管副总指挥宣布启动Ⅱ级响应，各应急救援小组按职责开展处置。

（3）Ⅲ级响应（黄色）。发生一般事件，车间可自行控制时，由车间主任组织处置，并报应急办备案。本节建议补充各响应级别的具体启动条件与责任人联系方式（AI 审查建议）
