```bash
  < backups/emergency_plan_20260917_173642.dump

docker start emergency-plan-backend

# 校验
docker exec emergency-plan-db psql -U postgres -d emergency_plan -c \
  "SELECT count(*) FROM enterprises;"   # 应回到 192
```

**重新生成备份**（推荐每次大改动前都做一次）：

```bash
# Windows 下请用 cmd 重定向，PowerShell 管道会破坏二进制
cmd /c "docker exec emergency-plan-db pg_dump -U postgres -d emergency_plan -Fc > backups/emergency_plan_YYYYMMDD_HHMMSS.dump"

# 校验文件头（应为 PGDMP）
```

> 项目自带 `scripts/backup.sh` 做同样的事，但它需要 bash 环境；
> 在 Windows + WSL 环境下够不到宿主 docker，故此处给出等价的直接命令。

## 三、改造期间的纪律

1. **每个计划独立 worktree + 独立分支**，分支名 `codex/<计划名>`，不在 master 上直接实现
2. **不删还原点**——三个还原点保留到本次改造全部验收通过
3. **每个计划完成后先跑全量回归**，失败数不得高于基线（`1549 passed / 4 failed`，那 4 个是既有失败）
4. **数据库迁移都是增量的**（`CREATE TABLE IF NOT EXISTS` / `ADD COLUMN IF NOT EXISTS`），可重复执行；**没有破坏性 DDL**
5. 需要真库验证的步骤在 worktree 里做不了（容器挂载主仓库），合并回 master 后补做
