# 系统易用性整体优化（傻瓜式操作 + 主线引导）— 设计规格

> **日期**：2026-08-08 | **状态**：设计中 | **依赖**：预案生成增强、预案附图扩展（已合入 master 94cc4bf）

---

## 1. 概述

本规格对系统做**一次整体易用性优化**，目标是让从未接触过系统的用户能在 10 分钟内从注册走到导出第一份预案，全程不需要理解 API Key、base_url、风险评估、风险分级管控等概念；同时保留内部人员的完整专业能力。

优化覆盖六个方面：

1. **基础层**：英文文案中文化、乱码、死按钮、权限菜单补全、入口去重、密码找回
2. **AI 配置收敛**：管理员统一配置全局模型，普通用户零配置
3. **主线引导**：首次登录 `/onboarding` 引导页（6 步）+ 工作台常驻完成度卡片
4. **创建流程重构**：替换 5 步向导，先生成样章确认再全量生成
5. **导航与信息架构**：普通用户菜单收敛为 4 项，专业模式展开完整功能
6. **移动端对齐**：完成度卡片 + 直达入口，移除用户级 AI 配置

实施方式：**一份总设计 + 单分支连续实现 + 一次性验收**（分支 `codex/usability-overhaul`）。

## 3. 设计原则

1. **默认傻瓜、高级可展开**：普通用户界面只保留核心任务路径，专业功能收进「专业模式」。
2. **AI 优先、人工兜底**：每步默认智能生成，但手动填写、导入现有数据始终可用；AI 产出均为「候选」，人工核对采纳后才落库。
3. **数据真实性护栏**：AI 不得编造企业事实（姓名、电话、地址等个人信息一律留空待填）；缺失信息在预案中输出「（待补充）」。
4. **客观数据直接导入**：高德周边查询等客观数据源（坐标计算方位/距离）走「预览 → 直接导入」，不走候选核对。
5. **复用优先**：引导页复用现有企查查填充、各模块 AI 生成弹窗、高德搜索、上传、表单组件，不新造第二套界面。
6. **增量不覆盖**：AI 生成支持「继续生成更多」，只追加新候选，已采纳数据不受影响。

### 3.1 企业信息卡片组件（EnterpriseInfoCards）

- 抽公共组件 `EnterpriseInfoCards`：企业名称输入 + 「AI 自动填充」（企查查）+ 关键字段卡片网格 + 「展开全部字段」抽屉（全部分组字段）。
- 使用方：引导页第 1 步、企业创建页、企业编辑页、企业详情「基本信息」tab（详情页为只读卡片 + 编辑按钮）。
- 四端共用一份组件与字段定义，避免「引导页一套、企业管理页一套」双份维护。
- 缺失字段在卡片上标「（待补充）」；完成标准沿用完成度算法（名称 + 地址 + 行业已填）。

## 4. 用户分层与专业模式

### 4.1 分层

- **普通用户**（企业安全员/负责人）：看到保姆式引导和收敛菜单，零 AI 配置。
- **内部人员/管理员**：完整菜单 + 管理功能 + 专业模式开关。

### 4.2 专业模式

- 位置：顶部栏（企业切换旁）「专业模式」开关，仅对有权限用户（管理员/内部角色）可见。
- 作用：展开左侧完整菜单（系统管理、AI 管理、法规库、风险方法等）。
- 默认状态：有权限用户默认关闭（收敛），可记忆用户偏好（localStorage）。

### 4.3 普通用户菜单（收敛后）

工作台 / 企业 / 预案 / 设置（仅个人资料）。AI 助手仅保留右下角浮动球。

### 4.4 权限补全

- 「法规库管理」纳入 `hasMenu` 过滤。
- `menuPermissions` 加载失败时：显示核心菜单（工作台/企业/预案/设置）+ 非阻塞提示「部分菜单加载失败」，不再静默。

## 6. 引导页 /onboarding

### 6.1 入口与形态

- 引导进度**按企业维度**（`/onboarding?enterprise_id=xxx`），一个用户多个企业时各自独立引导与完成度。
- 首次登录：创建第一个企业后自动进入该企业引导；之后新建企业也有独立引导入口。
- 存量用户（已有账号）：不强制进引导，工作台完成度卡片显示**当前企业**完成度，顶部企业切换时联动。
- 「稍后继续」随时退出，进度自动保存。
- 工作台「完成度卡片」点击「继续补数据」回到引导页当前企业对应步骤。
- 数据录完（1–5 步）后可「完成引导」；第 6 步为可选。

### 6.2 步骤总览

| 步骤 | 名称 | 数据来源 | 完成标准 |
|------|------|----------|----------|
| 1 | 企业信息 | 企查查自动填充 + 卡片核对 | 名称 + 地址 + 行业已填 |
| 2 | 组织架构 | AI 生成角色框架（姓名电话人工填） | 总指挥姓名已填 |
| 3 | 风险与危化品 | AI 候选 + 增量生成 + 导入 | 风险点 ≥1 或危化品 ≥1（已关联） |
| 4 | 应急资源 | AI 候选（内部 + 外部救援） | 内部或外部资源 ≥1 |
| 5 | 周边环境 | 高德周边查询（直接导入）+ AI 候选 | 周边单位或敏感目标 ≥1 |
| 6 | 生成并导出预案（**可选**） | 样章确认 → 全量生成 → 导出 | 完成即结束引导 |

### 6.3 每步三个入口（1–5 步通用）

每个数据步骤主视图默认展示「智能生成」，右上角常驻「✍️ 手动填写」，生成按钮旁为「📄 导入现有数据」：

1. **🤖 AI 生成候选**（默认）：填概况 → AI 生成候选 → 逐条核对采纳。
2. **📄 导入现有数据**：上传 xlsx / csv / docx / pdf → 解析 → LLM 按模块 schema 提取 → 候选（标注来源文件名+段落/行号）→ 逐条核对。
3. **✍️ 手动填写**：右侧抽屉复用现有录入表单（风险分级管控树、危化品表、组织架构编辑器等），填完关闭，数据总览刷新。

三者的数据写入同一份（引导页与企业详情页实时互通）；AI 候选不落库，采纳后写入对应业务表。

### 6.4 资料包导入（引导页顶部）

- 独立入口「📦 导入企业资料包」（步骤列表上方，可选）。
- 支持一次多文件（xlsx / csv / docx / pdf）。
- 流程：上传 → 文件/段落模块识别 → 按模块 schema 提取 → 自动分流到各步骤候选区。
- 步骤列表显示「(资料包)」标记；分流结果不落库，逐步骤逐条核对采纳。
- 与每步「导入现有数据」互补：资料包 = 一次撒网，每步导入 = 定点补漏。

### 6.5 增量生成

- 生成接口接收「已采纳清单」，提示词要求跳过重复、只生成新候选；后端按名称/场景做模糊去重兜底。
- 界面分「✓ 已采纳」（绿色只读）与「新增候选」（蓝色待核对）两区。
- 上一批未采纳候选可清空，不影响已采纳。

### 6.6 完成度算法

6 个模块加权，引导页与工作台卡片共用：

| 模块 | 权重 | 完成标准 |
|------|------|----------|
| 企业信息 | 10% | 名称 + 地址 + 行业已填 |
| 组织架构 | 15% | 总指挥姓名已填 |
| 风险与危化品 | 30% | 风险点 ≥1 或危化品 ≥1 且已关联 |
| 应急资源 | 15% | 资源 ≥1 |
| 周边环境 | 10% | 周边单位或敏感目标 ≥1 |
| 报告（风险评估 + 资源调查） | 20% | 两份报告均已生成（可跳过；跳过时风险评估报告权重归入「风险与危化品」，资源调查报告权重归入「应急资源」） |

完成标准均为「有内容」而非「填完整」；缺失字段标「（待补充）」。

## 8. 创建流程重构（替换 5 步向导）

- 类型选择（综合/专项/现场处置，专项多选事故类型）在引导页第 6 步或工作台快捷创建中完成；标题、编号、版本号自动生成，不再让用户填写。
- 创建后**先生成第一章样章**（用企业真实数据渲染），预览风格与内容。
- 不满意 → 「换风格重新生成样章」；满意 → 「生成全部章节」。
- 批量生成显示进度 x/y，可中途停止（已生成保留），失败章节单独重试。
- 完成后「导出 .docx」或「进入编辑器微调」。
- 替换 `PlanCreatePage` 的 5 步流程与 `auto_generate=1` 全量模式（改为 `auto_generate=sample` 仅样章）。
- `PlanCreatePage` 本身同步精简为两步（选类型 → 确认信息），编号/版本号移除；从工作台快捷新建进入的流程与引导页第 6 步一致。

### 8.1 编辑器增强（章节树图例 + 质量提示条）

- **章节树图例**：`SectionTree` 底部固定一行图例：「✓ 已完成 · ! 必填未完成 · ⏳ 生成中 · 🤖 可 AI 生成」，并提示「必填章节为空时导出会被拦截」。
- **章节质量提示条**：章节编辑区顶部展示质量校验结果（复用现有质量校验接口）：未覆盖要点时显示黄色「⚠ 本章可能未覆盖完整要点」+ 缺失项说明 + 操作（重新生成 / 查看要点清单 / 忽略）；合规时显示绿色「✓ 本章已覆盖全部要点」。导出预览页的校验保留。

## 9. AI 配置全局化

- `ai_config` 改为系统级单例：管理员在「AI 管理」配置 provider / API Key / 模型名（可含 temperature 等参数）。
- 生成、聊天、导入解析统一从系统配置取模型。
- 迁移：现有用户级配置合并为系统默认（保留一份，标记来源）；普通用户 AI 配置页隐藏。
- 未配置时：引导页/工作台显示非阻塞提示「AI 未配置，请联系管理员」；AI 相关操作禁用并引导联系管理员（不再弹「去配置」给普通用户）。

## 15. 错误处理

| 场景 | 行为 |
|------|------|
| AI 未配置 | 非阻塞提示「联系管理员」；AI 按钮禁用 |
| LLM 生成失败/超时 | 候选区显示错误 + 重试；已采纳数据不受影响 |
| 文件解析失败/格式不支持 | 明确错误提示 + 支持格式说明 |
| 高德查询无 GIS 坐标 | 弹窗引导先定位（复用 GisMapPicker） |
| 高德服务不可用 | 降级提示「暂时无法获取，可手动填写或 AI 生成」 |
| 资料包识别不到某模块 | 该模块无候选，用户可后续单独导入/生成 |
| 菜单权限加载失败 | 显示核心菜单 + 非阻塞提示 |
| 增量生成去重冲突 | 后端模糊去重，重复项直接丢弃并在提示中说明 |
