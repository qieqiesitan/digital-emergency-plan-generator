# 系统介绍 PPT 设计文档（客户/企业演示版）

> 日期：2026-08-21 | 类型：演示文稿设计 | 依据：功能清单.md、技术方案.md、PRD-00/PRD-11/PRD-12/PRD-14/PRD-15、docs/superpowers/plans（风险告知卡/隐患管理/企业驾驶舱/四色图/移动端）

## 1. 目标与受众

- 受众：企业客户 / 潜在用户（企业安全管理人员、安全负责人）
- 场合：5–8 分钟产品介绍演示
- 目标：讲清系统「解决什么问题 → 怎么用 → 有什么能力 → 为什么可信」，建立信任并引导试用
- 页数：10 页精炼版

## 2. 叙事结构（10 页）

| 页 | 主题 | 核心内容 |
|---|---|---|
| 1 | 封面 | 系统名 + 一句话价值主张（合规框架 + 数据/模板/AI 三合一 + 三类预案 + Word 导出） |
| 2 | 行业痛点 | 编制周期长 / 专业门槛高 / 内容易脱节 / 合规有风险（四卡片） |
| 3 | 系统定位 | 「把编制预案变成填数据+点生成」；三卡片（企业数据/国标模板/AI 引擎）+ 统计条 |
| 4 | 生成流程 | 四步闭环：数据录入 → AI 生成 → 人工精修 → 标准导出 |
| 5 | 核心能力 1 | 三类预案自动生成：综合 / 专项 / 现场处置 |
| 6 | 核心能力 2 | AI 生成引擎 2×2：多模型适配 / 流式输出 / 智能上下文注入 / 提示词可配置 |
| 7 | 核心能力 3 | 风险管理矩阵：风险评估报告 / 应急资源调查 / 法规库引用 / 风险分级管控 / 告知卡 / 隐患闭环 |
| 8 | 扩展能力 | 企业驾驶舱 / 移动端 PWA / 四色图 AI |
| 9 | 合规与安全 | 国标合规 / 公文导出 / 数据安全 / 部署灵活 |
| 10 | 总结 | 价值回顾（合规有据·生成高效·落地可用）+ 行动引导 |

## 3. 视觉系统

- 画布：16:9（13.33″ × 7.5″）
- 主色 深蓝 `1F3A5F`；页面背景 浅灰 `F5F7FA` / 白 `FFFFFF`；点缀 安全绿 `2E8B57`；次级文字 `6B7A90`
- 封面与末页深蓝底白字，内容页浅底深字（三明治结构）
- 字体：中文 Microsoft YaHei，数字/英文 Calibri（均为 Windows/Office 自带）
- 母题：圆角卡片 + 圆形图标底 + 统一 0.35″ 间距；不使用色条/装饰条
- 图标：react-icons → SVG → sharp 栅格化 256px PNG 嵌入

## 4. 版式规则（每页）

- 标题区：左上角 32pt 粗体标题 + 小字页码/章节；标题下不画线
- 卡片：圆角矩形 + 浅灰/浅绿底色 + 图标圆点；卡片间距 0.35″
- 流程页：横向四步，圆形序号 + 箭头连接
- 数据统计条：大号数字（44–54pt）+ 小标签
- 全部元素距边缘 ≥ 0.5″

## 5. 内容事实核对清单（防编造）

以下表述均有项目文档支撑，不得夸大：

- 三类预案（综合/专项/现场处置）与 GB/T 29639-2020 章节框架
- 风险辨识对接 GB 6441-2025（27 类事故）
- AI 层多模型适配（OpenAI/通义千问/文心一言/DeepSeek），用户自配 Key，API Key AES-256 加密存储
- JWT 双 Token（access 2h / refresh 7d），行级数据隔离
- docx 公文导出：封面/批准页/自动目录/多级编号/表格；黑体标题、仿宋正文、28 磅行距
- 扩展模块：风险评估报告、应急资源调查报告、法规库智能引用、风险分级管控（风险树/四色图/管控清单）、风险告知卡 + AI 标志审查、隐患管理、企业驾驶舱、移动端 PWA、四色图 AI
- Docker Compose 一键部署、支持私有化
- 不写未经验证的量化收益（如「效率提升 N 倍」）；「数周→数小时」仅出现在封面为定性表述「大幅缩短」

## 6. 实现与 QA

- 工具：pptxgenjs 脚本生成（临时目录安装依赖，不污染项目 package.json）
- 文本预算：生成器内估算文本宽度（CJK ≈ 1em/字，Latin ≈ 0.5em/字），超预算即告警/自动换行，防止溢出
- QA 三重：markitdown 内容核对；validate.py 结构校验；生成器几何断言（元素不越界、卡片不重叠）
- 产物：`数字化应急预案自动生成系统-系统介绍.pptx`（项目根目录）
