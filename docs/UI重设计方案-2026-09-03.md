# 数字化预案系统 — UI 重设计方案 v2（基于真实功能盘点）

**制定时间**：2026-09-03
**适用范围**：桌面端 (1440)+ 移动端 (390)
**核心原则**：设计稿 1:1 还原真实功能；不发明系统没有的页面、不省略已有的能力；以"少操作、能闭环、可信"为目标

---

## 〇、为什么重做

上一版画布 (file/721450739666930) 在未充分研究系统的情况下凭行业通用模板画了 23 页，导致：
- **结构脱离实际**：把"企业列表"画成 3 列网格、把"风险分级管控"画成 4 个独立子页——但实际是单页多 tab + 左侧分组导航
- **功能点错位**：把"预案编辑器"画成"大纲+正文+AI 侧栏"三栏——基本对，但忽略了"一键生成全部/SSE 流式进度/版本快照/导出前校验"等核心交互；图例区占位与真实不符
- **入口隐藏**：桌面端 7 个导航模块 + 10 个设置页 + 6 个企业模块 + 移动端独立路由 (`/m/*`) 都没梳理透
- **未解决既有硬伤**：①设计系统双轨 (antd 默认 + tailwind 死配置) ②驾驶舱深色与全站浅色割裂 ③统计数字字重弱 ④表格列宽不足 ⑤空态/失败态缺失

本版在系统功能盘点（详见 docs/系统全面审查报告-2026-09-02.md 和源码调研）的基础上，对**每条路由**给出改版要点，画布上落地时严格按此清单执行。

## 三、全局设计令牌（取代上一版"清新科技风"用色）

> 上一版用 `#2563EB` + `#0EA5E9` 双蓝偏冷，与企业级"安全"语义不完全匹配。改用与 antd v5 收敛的"稳蓝+橙警示"组合，**全部要落到 `ConfigProvider theme.token` 与 `tailwind.config.ts` 同步**，彻底解决双轨问题。

### 3.1 颜色令牌

| 用途 | 值 | 说明 |
|---|---|---|
| primary | **#1D4ED8**（蓝 700） | 主色，按钮/链接/选中态 |
| primary-hover | #1E40AF | |
| primary-soft | #EFF4FF | 浅底（选中行/标签底） |
| accent | #0EA5E9（天空 500） | 次主色，图表辅助线/链接 |
| success | #10B981 | 已完成/合规 |
| warning | **#F59E0B**（琥珀 500） | 待处理/质量提示 |
| danger | #DC2626 | 阻断/超期/已驳回 |
| 风险四色 | 红/橙/黄/蓝 = #DC2626 / #F59E0B / #EAB308 / #2563EB | 四色图标准（保持与现实监管一致） |
| 文字 | #111827 / #374151 / #6B7280 / #9CA3AF | 4 级 |
| 背景 | #F5F7FA（页）/ #FFFFFF（卡）/ #F9FAFB（表头） | |
| 边框 | #E5E7EB（次）/ #F3F4F6（弱） | |

### 3.2 字号（收敛到 7 级）

| token | px | 用途 |
|---|---|---|
| display | 32 | 工作台/看板大数字（**字重 700**——修复 A12） |
| h1 | 24 | PageHeader 主标题 |
| h2 | 20 | 卡片标题 |
| h3 | 16 | 区段标题 |
| body | 14 | 正文（antd 默认） |
| caption | 13 | 次要说明 |
| micro | 12 | 标签/提示（**全站最小字号**，禁止 <12px——修复 A4） |

### 3.3 圆角 / 阴影 / 间距

- 圆角：`4 / 8 / 12 / 16`——按钮 8，卡片 12，Modal 12，输入 8
- 阴影：`0 1 2 rgba(16,24,40,.05)` + `0 4 12 rgba(16,24,40,.08)`（双层）——全局统一
- 间距栅格：4 / 8 / 12 / 16 / 24 / 32（与 antd Space 对齐）

### 3.4 字体

- 中文：`PingFang SC`（mac）/ `Microsoft YaHei`（win）——不强行 webfont
- 英文/数字：`Inter`（v1 段打包，~150KB sub 集）
- 数字场景：表格内数字统一 `font-variant-numeric: tabular-nums`

### 3.5 图标

- 全站 **antd icons**（@ant-design/icons）线性，统一描边
- **禁止** emoji 混用——尤其预案编辑器章节树要去掉 🤖⏳❗️⚠️
- 自定义图标（驾驶舱、四色图工具栏）走 antd icon + 业务描边补充

### 3.6 驾驶舱的"暗色"问题

- **改浅色**：与全站统一浅底 + 蓝主色
- 保留"实时感"：用浅色渐变背景 + 雷达扫描 CSS 动画，不靠霓虹
- 模块入口卡保留"hot 角标"等克制的视觉强调

## 四、桌面端页面设计要点（1:1 映射真实路由）

> 格式：路由 → 一句话 → 改版要点（合并既有硬伤 + 业务修正）

### 4.1 登录/注册

- **/login 登录**
  - 上一版分屏保留；但**桌面端要补"忘记密码"入口**（I6 缺）→ 简单 modal：邮箱 + 提示"系统未启用自助重置，请联系管理员"
  - 错误条顶部居中（I1 ✅）
  - 登录按钮"加载态"明确防重复
- **/register 注册**
  - 密码强度计（I3 ✅）+ 弱密码实时阻止提交
  - 邀请码字段（若有后端则展示）放表单底部说明

### 4.2 工作台 /dashboard

- 上一版基本结构对，但 4 统计卡数字字重 400 偏弱（A12）→ **改 32px/700**
- "企业概览"卡片：补**地址或统一社会信用代码**做次级区分（A17）
- "最近编辑"列表：章节完成度用 Progress + 数字，状态用 antd Tag
- **新增**：空态有"创建第一个企业"+"新建预案"两个 CTA 按钮（不只一行灰字）
- 卡片右上增加"快捷操作"下拉（编辑信息/进入驾驶舱/删除），减少按钮外露

### 4.3 预案管理

- **/plans 预案总览**
  - 双视图（卡片/列表）保留
  - 卡片态企业名 ≤14 字截断 + tooltip 全称 + 显示行业 Tag + 预案计数彩色分组（红/橙/蓝）
  - 列表态列宽收敛，避免"未设置地址"占据大半列
- **/enterprises/:eid/plans 列表**
  - 类型 Tab 改为 Segmented（I14 修复），不要下划线 + 描边混合
  - 状态筛用 Select
  - 搜索改为**即时**（200ms 防抖），不按回车
- **/plans/new 新建向导**
  - 步骤0 三张类型卡：图标 + 标题 + 适用场景 + 选中高亮边框
  - 步骤1 Descriptions 紧凑：企业/类型/事故类型
  - **顶部"返回"按钮位置突出**（防向导中迷路）
- **/plans/:id/edit 编辑器（重点重做）**
  - 三栏（章节树 280 / 富文本 弹性 / AI 侧栏 0/320 可切）
  - **顶部工具栏顺序**：标题 + 状态 Tag + "当前版本 Vx" + 右侧按钮组：[创作风格][AI 审查][版本历史] | [保存版本] [导出]
    - "一键生成全部"独立为页面顶部大按钮（占位 1/2 宽），含 SSE 进度条；生成中变"停止"
  - 左栏章节树：去 emoji！用 antd `FileTextOutlined` 节点图标；生成中节点加 Loading；右上"展开/收起"
  - 中栏：标题 + 字数 Badge + 操作行（自动填充/AI 续写/插入图）+ RichTextEditor（去掉图例 emoji 段，A18）
  - 状态条：底部一行 "保存中/已保存 x 秒前/失败"
  - 异常：AI 未配置显示顶部引导条 AiNotConfiguredHint（I7 修复）
  - sampleDone 横幅：样章生成完成提示用户"采纳全部"或"逐章审阅"
- **/plans/:id/versions 版本列表**
  - 列：版本号 + 当前 Tag + 类型（自动/手动）+ 说明 + 时间 + 操作（查看/回滚）
  - 1 条数据时**不显示分页器**（I 修复）
- **/plans/:id/preview 导出预览**
  - 上一版"模板"基本对——保留：校验 Alert 分级（错误红阻断+黄质量提示）+ 一键去编辑
  - 正文 `<mark class="quality-issue">` 高亮保持
  - 打印/下载 docx 按钮右上方

  - 表头列宽：行业 100/员工数 90/风险 90/预案 90/完成度 140/操作 160（**按 px 给最小宽**——A16 修复）

## 八、画布上落地时的执行规范（沿用 09-02 经验 + 本次修正）

### 8.1 硬规则（与 09-02 一致）

- 横向一字排开，每页 1440×980，间隔 60px
- 字号不许 <12px
- Noto Sans SC 不支持 Bold/SemiBold/Medium 字重 → 用 `fontWeight: 700` 让浏览器模拟
- 长文节点易丢 → 单独写"补全"批处理兜底
- "v" 字符 Inter Bold 偶尔失败 → 用 "√"
- 中点 "·" 解析失败 → 用 " · "（前后空格）
- SVG path 多个 M 起点易解析失败 → 简化形状
- SOLID fill 不要带 `a` 字段
- 三栏布局中间列 `layoutGrow:1` + `width:"fill_container"`

### 8.2 新增规则（本版强化）

- **每页必须画"加载/空/失败"三态示意**（至少空态）——与既有硬伤对应
- **每页顶部 token 化色板占位**（小色块对齐用）——保证不双轨
- **图标用 antd 风格**——禁止 emoji
- **驾驶舱的暗色版不要画**——直接做浅色
- **"v1.x 快照状态"等内部版本号不要漏**——告知卡列表要画

### 8.3 不做（避免上版错误）

- 不要在根侧边栏画"风险/隐患/法规"
- 不要在企业列表画 3 列网格
- 不要画"发布"或"运维监控"等系统没有的页面
- 不要造"通知中心""消息"等不存在的功能
- 移动端不做"非 /m/* 路由"的页面
- 不要画"系统介绍 PPT 风格"页
