# PRD-09：系统设置

> **版本**：1.0 | **创建日期**：2026-06-05 | **依赖**：PRD-00, PRD-01, PRD-04

---

## 1. 模块概述

系统设置模块聚合用户的个人账户管理和 AI 模型配置功能。在侧边栏底部以"设置"入口呈现，展开为两个子页：个人资料、AI 配置。

**注意**：个人资料的 API 已在 PRD-01 中定义（`/api/v1/users/me`），AI 配置的 API 已在 PRD-04 中定义（`/api/v1/settings/ai-config`）。本 PRD 聚焦于前端页面整合与交互流程。

---

## 2. 功能点

| 编号 | 功能 | 描述 | 优先级 | API 归属 |
|------|------|------|--------|----------|
| I01 | 个人资料查看 | 显示姓名、邮箱（只读） | P0 | PRD-01 |
| I02 | 修改姓名 | 表单修改姓名 | P0 | PRD-01 |
| I03 | 修改密码 | 旧密码 + 新密码 + 确认 | P0 | PRD-01 |
| I04 | AI 模型配置 | 选择提供商、填写 API Key、测试连接 | P0 | PRD-04 |

---

## 3. 前端路由

```
/settings
  /settings/profile      → 个人资料
  /settings/ai-config    → AI 模型配置
```

侧边栏设置区域：

```
──────────────
  设置
  ├─ 个人资料
  └─ AI 配置
──────────────
```

### 4.2 修改姓名

点击"编辑"→ 姓名变为输入框 → 确认/取消

**交互**：
- 点击编辑 → 文字变输入框 + 保存/取消按钮
- 保存成功 → 顶部用户名称同步更新
- 保存失败 → 红色错误提示

### 4.3 修改密码

**校验规则**：
- 原密码必须正确
- 新密码 ≥ 8 位，包含字母和数字
- 新密码不能与原密码相同
- 两次输入一致

**成功处理**：
- 提示"密码修改成功，请重新登录"
- 清除所有 Token
- 2 秒后跳转登录页

### 5.2 提供商切换行为

切换提供商时：
1. 自动填入该提供商的默认 `base_url`
2. 自动填入该提供商的默认 `model_name`
3. API Key 字段清空（安全性考虑）
4. Temperature/max_tokens 恢复默认值

### 5.3 测试连接

点击"测试连接"：
1. 用当前填写的参数调用 `POST /api/v1/settings/ai-config/test`
2. 显示 Loading 状态（按钮变灰 + 旋转图标）
3. 成功：显示绿色"连接成功，模型: gpt-4o"
4. 失败：显示红色错误详情（"401: API Key 无效" / "网络超时" / "模型不存在"）

**测试时不保存配置**。用户需点击"保存配置"才会持久化。

### 5.4 API Key 显示

- 默认：`••••••••••••`（密码遮罩）
- 点击"显示"：显示明文 3 秒后自动恢复遮罩
- 编辑时：正常输入框

### 5.5 无 AI 配置时的引导

如果用户未配置 AI 模型就进入预案编辑器并点击 AI 生成：

```
┌─────────────────────────────┐
│  ⚠ 尚未配置 AI 模型          │
│                              │
│  使用 AI 生成功能前需要先     │
│  配置大语言模型。             │
│                              │
│        [去配置]  [取消]       │
└─────────────────────────────┘
```

点击"去配置"→ 跳转 `/settings/ai-config`
